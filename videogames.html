🧩 MazePlatform

Status: Work in Progress – playable demo link coming soon.

A classic maze‑tilting ball game built entirely in C++ with Unreal Engine. The player tilts a platform to guide a physically simulated ball through a procedurally generated maze. Maze layout is defined by a simple text grid (# = wall, o = cone), making levels extremely easy to modify.

The project demonstrates procedural level creation, real‑time physics interaction, and pure C++ integration without any Blueprint logic. All key parameters (tilt speed, max angle, etc.) are exposed for tuning.
